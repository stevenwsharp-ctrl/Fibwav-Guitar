# Fibwave Guitar

Fibwave Guitar is a music visualizer for guitar practice. It shows Fibonacci patterns that move with the sound.

## Open the app

**[Click here to open Fibwave Guitar](https://stevenwsharp-ctrl.github.io/fibwav-guitar/)**

## How to use

1. Click the link above.
2. Let the browser use your microphone or sound, if it asks.
3. Play your guitar and watch the patterns.

## Files

- `index.html` — the app. GitHub Pages opens this file.
- `fibwave-guitar.html` — a copy of the app.
